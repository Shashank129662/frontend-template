# Next.js production

Inspect the repository before changing it. Keep App Router and pnpm. Prefer server components; make the smallest necessary client boundary. Use Tailwind for component styling, `next/image` for local imagery, and `next/link` for internal navigation. Keep substantial pages compositional, use meaningful types, avoid `any`, and separate repeated static data from JSX only when useful. Run `pnpm lint`, `pnpm typecheck`, and `pnpm build` before completion.
